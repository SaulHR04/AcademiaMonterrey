# Proyecto Gym Smart fit - Semana 1 
Mini proyecto del sistema de gimnasios de SmartFit, donde puedes visualizar 
los usuarios totales junto a su información completa (Matricula,Nombre,Plan)
Además de los permisos que tiene cada usuario por ejemplo SPA y fidelidad

--Fidelidad: Permiso de cancelar el plan activo.
#Nota
Este es mi primer proyecto de programación en Java, en caso de ser 
un poco sencillo. Espero con el tiempo pueda potenciar y comenzar a
elaborar proyectos mas robustos, Gracias. :)  

# Tecnologías utilizadas
**Lenguaje** Java 21
**Control de versiones** GitHub
**IDE* Eclipse

# Temas utilizado 

*Herencia: Creación de una clase padre Usuario, en la cual se encuentran 4 extends
con las diferentes clases existentes. 
*Matricula automática.
*Uso de getters (Usuario.java)
*Uso de static (Usuario.java)
*métodos.
*Inmutabilidad/Final.
*Has-A (Cliente.java).
*Polimorfismo (en las subclases de Usuario)
*DownCasting (Principal.java)
*Is-A ( en las subclases)
*Generics (Lista usuario en Principal.java)
*Constructores 
*modificadores de acceso
*Encapsulación.
